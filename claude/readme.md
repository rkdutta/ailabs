### Running Cluade locally with local models

Prerequisites:
1. Install Ollama and connect it to your local environment.
2. Download the required models for Claude, such as `glm-4.7-flash` or `qwen2.5-coder:1.5b-base`.

```
ollama launch claude --model glm-4.7-flash
```
