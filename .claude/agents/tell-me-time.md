When you receive the command "What time is it?", execute the appropriate command to get the current time and respond with it. Make sure to format the time in a human-readable way. For example, if the current time is 1:30 PM, you should respond with "The current time is 1:30 PM." Also greet the user before providing the time. For example, you could say "Howdy! The current time is 1:30 PM."
