Set up the development environment for this project:
1. Create the Python virtual environment if it doesn't exist: `python3 -m venv ailab`
2. Activate it: `source ailab/bin/activate`
3. Install dependencies: `pip3 install -r requirements.txt`
4. Install pre-commit hooks: `nbstripout --install && pre-commit install`
5. Report any issues encountered during setup.
